# Gaming Rig
Setup for gaming in 1080p 144hz HDR. With this setup i'm able to play games like AC Valhalla, Control, Far Cry 6, War Dogs 2 with max quality no OC. All games play well beyond 60 fps. Most games can break 100fps and GPU temp stays in the 60's C.
